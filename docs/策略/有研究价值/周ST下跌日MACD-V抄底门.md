| 项目 | 内容 |
|---|---|
| 状态 | 有研究价值（弱：开门极少，样本只有约 3 年） |
| 更新 | 2026-11-17 |
| 标的与周期 | BNB、SOL 现货口径 5m 数据，周线 ST + 日线 MACD-V 开关 |
| 样本区间 | 2023-10-22 ~ 2026-10-22（数据只从 2023-08 起，旧研究的 2022~2023 早期熊市段无数据） |
| 试验次数 N | ≥84（旧研究 40+44 组候选；本次只重跑了“基准”和“抄底门”两个） |
| 复现 | 先建目录链接：`.cache/dstudy/dca_indicator_study/5m` 指向 `数据/加密货币/5m`，然后 `python -m research.run dca_macd --strategy st_macd --legacy-data-root .cache/dstudy --output .cache/st_macd.json` |

## 1. 做什么
DCA 买入的开关：币自己的周线 ST 处于下跌，并且日线 MACD-V 出现极端值（预警）时才开门抄底，其余时间不买。目的是只在深度超跌时进场。

## 2. 规则
- 开门：本币周线 ST 为下跌，且日线 MACD-V 触发极端条件（`extreme_SELF_p6`）；
- 基准（原门）：不加极端条件的原开关。
- 买入、止盈用 DCA；这个实验是现货口径，没有杠杆、资金费和滑点。

## 3. 回测设置
| 项目 | 取值 |
|---|---|
| 数据 | `数据/加密货币/5m/BNBUSDT_5m.npy`、`SOLUSDT_5m.npy` |
| 手续费 | 每边 0.018% |
| 资金费 | 不适用（现货口径） |
| 滑点 | 0 |
| 账户口径 | 两币各 1000，合并计算；成交路径两种（OHL/OLH）取较差者 |
| 样本外划分 | 无事先划定的样本外 |

## 6. 局限与风险
- 只有 BNB、SOL 两个币；旧研究称 BNB 只开门 4 次、SOL 2 次（本次未核）。
- 持仓最长 100 天，SOL 回撤 24.4%（BNB 11.4%），单币风险比合并结果大。
- 样本不含 2022 年熊市，而这个门本来就是为熊市抄底设计的。

## 7. 与旧文档的差异
- 旧汇总：连续收益 62%、回撤 23%、夏普 0.90。本次近 3 年重跑为 +23.4% / 15.4% / 0.74，**不一致**。原因：旧研究的“连续”段从 2022-01 起，新仓库 5m 数据 2023-08 才开始，所以旧数字无法复现，旧数字作废，以本表为准。
- 旧汇总称这是 40+44 组候选里“唯一保留研究”的一个；本次没有重跑其余候选。
