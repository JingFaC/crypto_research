| 项目 | 内容 |
|---|---|
| 状态 | 有研究价值 |

| 复现 | `python -m research.run soxl --strategy kdj_ema --data-root 数据 --funding research/soxl/inputs/SOXLUSDT.funding.json --output .cache/kdj_ema.json` |

## 1. 做什么
在 EMA 多头/空头排列的方向上，等 J 值超卖/超买后顺势进场，快速回到均值就平仓，赚短线回归的薄利。

## 2. 规则
- 指标：KDJ(14,3,3)；EMA 5/20/60。
- 做多：EMA5>EMA20>EMA60 且 J 刚跌破 10。做空：EMA5<EMA20<EMA60 且 J 刚升破 90。
- 只在美东常规交易时段入场。
- 信号在 K 线收盘确认，下一根开盘成交。
- 平仓：K 值回到 50；最长持有 36 根。
- 无止损。

## 3. 回测设置
| 项目 | 取值 |

| 手续费 | 每边 0.04% |
| 资金费 | 真实资金费（`research/soxl/inputs/SOXLUSDT.funding.json`） |
| 滑点 | 无额外假设 |
| 账户口径 | 自身账户：满仓名义，另给 10% 名义口径 |
| 样本外划分 | 无事先划定的样本外；仅有前后半段对比（未重跑） |

## 6. 局限与风险
- 样本只有 SOXL 下跌 66% 这一段行情，没有上涨行情数据；样本不足一年。
- 利润集中在空头（+0.64%/笔），多头仅 +0.14%/笔，接近成本。（旧文档数字，本次未重跑）
- 参数是看过数据后选的，有选择偏差。
- 其他 21 个美股/ETF 永续上合计净利≈0；滚动验证≈0。（旧文档数字，本次未重跑）
- SOXL 与 SOXS 逐日盈亏相关 0.93，不是独立证据；与[ST-SAR网格](ST-SAR网格.md)的利润都来自 SOXL 下跌段（推测：同时运行等于加倍押同一行情）。
