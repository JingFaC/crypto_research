# ETH日线ST翻转做多

| 项目 | 内容 |
|---|---|
| 状态 | 有研究价值 |
| 更新 | 2026-11-17 |
| 标的与周期 | ETHUSDT 永续，日线 |
| 样本区间 | 2020-01 ~ 2026-11（2500 天） |
| 试验次数 N | ≥36（旧研究：ST 长度 4~20 × 倍数 1.5~4.0 的 36 格邻域；其余未统计） |
| 复现 | `python -m research.run st_boll --strategy daily_st --symbol ETHUSDT --data-root 数据 --output .cache/eth1d.json` |

**规则**：Supertrend(6, 2.5) 日线翻转为多时，下一根开盘买入；翻转为空时，下一根开盘卖出。只做多，无止损，复利无杠杆。

**回测设置**：每边手续费 0.05%；多头资金费 0.01%/8h（固定假设）；滑点无；数据 `数据/加密货币/1d/ETHUSDT_1d.json`。

**结果**

| 指标 | 基准 | 成本×2 |
|---|---|---|
| 笔数 | 33 | 33 |
| 总收益 | +2864% | +2015% |
| 年化 | 64.1% | 56.2% |
| 最大回撤 | -67.1% | -67.8% |
| 夏普 | 1.16 | 1.07 |
| 胜率 / 盈亏比 | 51.5% / 4.08 | — |
| 最差一笔 | -17.8% | — |

分年收益（日历年）：

| 年份 | 收益 |
|---|---|
| 2020 | +432.1% |
| 2021 | +329.0% |
| 2022 | -33.2% |
| 2023 | +37.8% |
| 2024 | +2.3% |
| 2025 | +25.3% |
| 2026（未满年） | +10.0% |

**评价表**

| 编号 | 指标 | 数值 | 过线 |
|---|---|---|---|
| G1 | 夏普 且 卡玛 | 夏普 1.16；卡玛 64.1/67.1≈0.96 | ✗ |
| G2 | 最大回撤 ≤15% | 67.1% | ✗ |
| G3 | 逐年盈利 | 2022 年 -33.2% | ✗ |
| G4 | 样本外>0 | 无事先划定的样本外 | — |
| G5 | 成本×2>0 | +2015% | ✓ |
| G6 | 去最赚 5%>0 | 去掉最赚 1 笔后复利仍 +634% | ✓ |
| G7 | ≥300 笔 | 33 笔 | ✗ |
| G8 | 容量 | 未计算 | — |

判定：无硬性失败（G5、G6 过线）；G1、G2、G3、G7 不过，G4、G8 无数据 → **有研究价值**。回撤 67.1% 很深，但本项目没有“回撤超过多少就否决”的规定，只在 G2 不过。

**说明**
- 信号不是随机的（旧研究：随机平移后不输给它的比例仅 1.4%，本次未重跑），但笔数太少、回撤太深、收益集中在 2020~2021。
- 只测了 ETH 一个币。全币池见[已否决](../已否决.md#日线st翻转做多全币池)；大币等权组合见[大币日线ST组合](大币日线ST组合.md)。
- 若把它当“低频趋势仓位”而不是高频低回撤策略，需要另行定义标准，目前不在评价范围内。

**与旧文档的差异**：笔数、总收益、年化、回撤与旧汇总一致。旧汇总的分年数字（2020 +1043%、2021 +100%）按**开仓年**归属，本表按**日历年**，口径不同，不是错误。
