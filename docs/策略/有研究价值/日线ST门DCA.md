# 日线ST门DCA

| 项目 | 内容 |
|---|---|
| 状态 | 有研究价值 |
| 更新 | 2026-11-17 |
| 标的与周期 | BTC、ETH、BNB、SOL、XRP、DOGE、ADA、TRX、LINK、LTC 十个币永续，1h 数据，日线 ST 开关 |
| 样本区间 | 2020 ~ 2026-10 |
| 试验次数 N | ≥4（自身门/BTC 门 × ST(10,3)/ST(6,2.5)；旧研究还试过其他门，未统计） |
| 复现 | `python -m research.run dca_macd --strategy daily_st_numpy --output .cache/daily_st_numpy.json` |

## 1. 做什么
日线 Supertrend 转多时开启 DCA（逢跌加仓、固定止盈），转空时退出；门可以用币自己的 ST（自身门），也可以统一用 BTC 的 ST（BTC 门）。

## 2. 规则
- 门：日线 ST，长度/倍数取 (10, 3.0) 或 (6, 2.5)；自身门用该币自己的日线，BTC 门用 BTC 的日线。
- DCA：档距 0.667%（0.2/30），最多 30 档，加仓量 ×1.1，止盈 1.5%，单币预留资金 10000，杠杆 1 倍，不复利。
- 门关闭即退出本轮；开门后前 720 根 1h 不入场（预热）。
- 本次用的是 30 档数值协议，**不是**旧文档里 20 档的 native 协议（后者依赖 nautilus_trader 引擎，本仓库不使用；用本仓库引擎重跑 20 档版本是后续工作）。

## 6. 局限与风险
- 不计资金费，对长期持仓偏乐观。
- 十个币都是当前仍在的主流币，有幸存者偏差（推测）。
- 后段（2025-07 起）明显弱于前段，BTC 门在 2025 年亏损；自身门最差一轮 -47.9%。
- 收益里 2020~2021 占大头。

## 7. 与旧文档的差异
- 旧汇总把“日线 ST 门 + DCA”判为**已否决**，依据是 native 20 档协议下“基准净利/入金仅 +2.73%”。该协议本次无法重跑，所以那条结论仍无数据支撑。
- 旧汇总的“自身门单轮最差 -47.9%”“BTC 日线门最近一段夏普 0.4~0.7、2025 年亏”与本次重跑一致。
- 本次用 30 档数值协议、按[评价标准](../../方法/评价标准.md)机械判定，没有硬性失败，所以归“有研究价值”。这与旧结论不同，不是矛盾：两者协议不同。
