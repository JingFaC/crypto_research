# EMA排列开关门DCA

| 项目 | 内容 |
|---|---|
| 状态 | 有研究价值 |
| 更新 | 2026-11-17 |
| 标的与周期 | 前 20 币池（按成交额排名，月度更新）永续，1h 数据，4h EMA 排列开关 |
| 样本区间 | 2021-01 ~ 2026-11 |
| 试验次数 N | ≥72（旧研究：72 组 周期×快中慢 参数；本次只重跑选定的 4h EMA10/30/80） |
| 复现 | `python -m research.run dca_macd --strategy ema_dca --ranking-file 数据/研究输入/univ.pkl --output .cache/ema_dca.json` |

## 1. 做什么
EMA 多头排列时才允许做多 DCA（逢跌加仓、固定止盈），排列破坏就退出，用趋势开关替 DCA 挡掉大熊市。

## 2. 规则
- 开关：4h EMA10/30/80 多头排列开门；排列破坏即退出本轮。
- DCA：档距 1%，最多 20 档，加仓量 ×1.1，止盈 1.5%，单币初始资金 10000，复利关闭。
- 币池：每月按成交额取前 20 名，上市满 1 年（2023 年起满 3 年）。
- 账户：同时最多 10 轮，超出的新轮被跳过。
- 杠杆：分别测 1 倍和 3 倍。

## 3. 回测设置
| 项目 | 取值 |

| 手续费 | 每边 0.05% |
| 资金费 | **不计**（项目决定，见[回测规范](../../方法/回测规范.md)第 2 节）；与旧回测口径不同 |
| 滑点 | 0 |
| 账户口径 | 自身账户 |
| 样本外划分 | 无事先划定的样本外；旧研究的 B 段（2025-07 起）本次未重跑 |

## 6. 局限与风险
- 不计资金费，对长期持仓的 DCA 偏乐观，实际结果会更差；需要真实资金费才能确认。
- 2025 年几乎不赚钱（1 倍 +2.6%，3 倍 +0.7%）；旧文档称 2025-26 夏普 0.92、收益远低于直接持有（+276% 对 +1739%）。（旧数字，本次未重跑）
- 3 倍复利在更大币池（X 池）上，旧文档称 96 个币爆仓 38 个、2025-10-10 一天 7 个。（旧数字，本次未重跑，结论是“冻结配置未通过”）
- A 段选出的 1h 20/30/60 在 B 段夏普只有 0.14，A、B 段夏普负相关（-0.46）；只有“邻域整片稳健”才算数。（旧数字）
- 币池按“当前仍在”的币构造，有幸存者偏差。（推测）

## 7. 与旧文档的差异
- 本次口径不计资金费，且只重跑了 4h EMA10/30/80；旧文档的 A/B 段夏普、X 池爆仓数均未复现。
- 旧文档说“全样本夏普高、回撤小”，本次重跑方向一致。
