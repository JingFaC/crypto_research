# 评价标准

所有策略用同一张评价表、同一套判定规则。本文件是唯一的标准出处，策略文档只引用，不重复。

## 1. 先区分“文献依据”和“本项目默认”

| 类别 | 含义 | 能否随意改 |
|---|---|---|
| 文献依据 | 有论文原文支持的方法（见第 6 节） | 不能放松 |
| 项目默认 | 本项目自己定的数值线，没有文献给出通用阈值 | 要改必须改本文件，并重判所有策略 |

文献并没有给出“夏普≥多少、回撤≤多少才算合格”的通用线（[LuxAlgo 的回测指标指南](https://www.luxalgo.com/blog/top-7-metrics-for-backtesting-results/)也明确这么说）。所以下面的数值线都是**项目默认**，只用来在本项目内部统一比较，不代表统计意义上的证明。

## 2. 第一关：回测有效性（全过才谈绩效）

任何一项不过，这次回测的数字作废，不进入绩效评价。

| 编号 | 检查项 | 判定 |
|---|---|---|
| V1 | 无后视：信号只用已收盘的数据，成交在下一根开盘 | 见[回测规范](回测规范.md)第 1 节 |
| V2 | 成本完整：手续费、资金费、滑点假设都写明 | 缺一项即不过 |
| V3 | 数据来源可追溯：数据清单里有对应文件与 SHA256 | 否则不过 |
| V4 | 试验次数 N 已登记：本策略调过多少组参数/变体 | 可写下限并注明来源；完全不知道则不过 |
| V5 | 结果可由 `research/` 里的代码一键复现 | 不能复现则先补代码；补不了才归“归档” |

## 3. 第二关：绩效评价表（8 项，项目默认线）

每个策略都输出同一张表，逐项写“数值 / 是否过线”。

| 编号 | 指标 | 过线条件 | 作用 |
|---|---|---|---|
| G1 | 夏普 且 卡玛 | 夏普≥1.5 且 卡玛≥1.5 | 收益相对波动与回撤 |
| G2 | 最大回撤 | ≤15% | 可承受性 |
| G3 | 逐年盈利 | 至少 3 个完整年度，且每个完整年度盈利 | 不靠单一行情 |
| G4 | 样本外 | 事先划定、只用一次的检验期收益>0 | 防过拟合 |
| G5 | 成本×2 | 成本加倍后收益仍>0 | 对成本不过度敏感 |
| G6 | 去极值 | 去掉最赚的 5% 笔后收益仍>0 | 不靠少数大单 |
| G7 | 样本量 | ≥300 笔 且 平均每天≥1 笔 | 统计量够大 |
| G8 | 容量 | 触及杠杆上限而被缩仓的笔数≤10% | 能真实执行 |

统一账户口径（沿用原评估器）：每笔风险=账户 0.25%（按止损距离折算名义）、总名义杠杆上限 3 倍、往返成本 0.1%（压力 0.2%）、按日权益。没有止损距离的策略（网格、DCA）不能套这套口径，改用**策略自身账户口径**，并在表里标注“口径：自身账户”。

## 4. 第三关：判定（机械，不凭感觉）

**硬性失败**（任一项即“已否决”）：G4 样本外≤0；G5 成本×2≤0；G6 去极值≤0。回撤只通过 G2（≤15%）评价，**没有“回撤超过多少就否决”的规定**。

| 状态 | 条件 |
|---|---|
| 达标 | 通过第一关，G1~G8 全过，且统计证据（第 5 节）不否决 |
| 有研究价值 | 通过第一关，无硬性失败，但 G1~G8 没全过 |
| 已否决 | 通过第一关，有任一硬性失败 |
| 归档 | 没通过第一关，且规则、代码或数据在本仓库无法重建；不参与评判，只留档 |

**“归档”不是“否决”也不是“有希望”**：它只表示本仓库没法重建这条策略的回测，旧文档里的结论只能当线索。规则和代码能在本仓库补齐的，补齐后重跑再判定，不要停在归档。

当前没有任何策略“达标”。“有研究价值”只表示值得继续验证。

## 5. 统计证据（文献依据）

- **试验次数**：只报告选出来的那个最好结果会高估表现。必须登记 N，并说明 N 个试验里是否都报告了。
- **折算夏普（DSR）**：未折算试验次数的夏普不能当发现（Bailey & López de Prado 2014，见[SSRN 摘要](https://papers.ssrn.com/abstract=2460551)）。
- **最短回测长度（MinBTL）**：N 个独立试验下，样本年数需要大于 2·ln(N)/E[max_N]²，否则一个样本内夏普为 1 的策略，样本外期望也可能为 0（同上）。例：只有 5 年数据时，独立配置不应超过约 45 组。
- **多重检验**：同一数据上试得越多，t 值要求越高，不能再用单次检验的 2 作为线（Harvey & Liu，*Backtesting*，[原文](https://people.duke.edu/~charvey/Research/Published_Papers/P120_Backtesting.PDF)）。
- **样本外检验**：单次留出样本可能已被研究者看过，所以“样本外”必须在方案里事先划定、只用一次。

**当前实现状态**：DSR、MinBTL、PBO、White/Hansen 检验在本仓库**尚未实现**。因此所有策略的“统计证据”一栏统一写“未实现”，**不得**用名义夏普或总收益最大当作显著的理由。

## 7. 与旧版标准的差异

旧版“评价体系 v1”只存在于旧仓库的评估脚本和汇总文档，没有独立文件。本次改动：

1. 把“文献依据”和“项目默认线”分开写，旧版混在一起。
2. 新增第一关（有效性）和“归档”状态：旧版把“没跑过”也写成“已否决”；本版没重建的只归档，不下结论。
3. 把硬性失败条件写成明文规则，旧版靠人工判断。
4. 旧脚本里的“月为正≥65%”条件没有出现在旧文字标准里，本版不采用（月度样本太小，噪声大）。
