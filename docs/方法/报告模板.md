# 报告模板

每个策略一个文档，章节、顺序、表头完全一致。复制下面的模板，替换尖括号内容；没有的数据写“—”，不要删行。

文件命名：`<策略名>.md`。文件名不带日期、不带编号。日期只写在文档开头的“更新”一行。

## 填表规则

- “过线”列只用三个符号：✓ 过、✗ 不过、— 没有数据。
- 数字要能追到 `.cache/` 里的 JSON 或 `docs/数据/` 的文件；追不到的不写。
- 旧文档里没重跑的数字，不写进结果表，只能写进[归档](../策略/归档.md)的“原声称”列。
- “已否决”的策略可以不单独成文件，合并写进[已否决](../策略/已否决.md)，但章节和表头仍按本模板。
